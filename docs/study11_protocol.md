# Study 11 controls

These controls use the existing, inspected HABS development set. They constitute a retrospective robustness study. No independent external cohort or sealed test is available. Splits separate participant IDs, which may represent the same individual across cohorts.

## Classification

- **Training budget.** Each of nine ID-by-theme cells is the common test set for all four conditions. R1 samples from all other trials, R2 excludes the test theme fold, R3 excludes the test ID fold, and R4 excludes both. Within each cell, R1–R3 draw without replacement the same number of training rows as R4, with ten predetermined seeds. Both the 448-feature multimodal model and frozen REVE use the same sampled rows. The full-pool arm uses these same test cells. Consequently its R1 differs from the published five-fold random R1. Report mean within-ID AUC over seeds, variability across seeds and paired ID-bootstrap intervals for R4 minus R1.
- **Post-clip window.** Compare four-phase Ridge to the same pipeline after removing all explicit post-clip changes and transitions. Training and evaluation rows are held fixed. This compares nominal feature windows in the archived data; the archival EEG filters can still use later samples.
- **Session time.** Compare predictors using trial position, a cohort-by-position interaction, nominal pre-stimulus physiology, and preceding-trial physiology. Index and predecessor are determined before removing non-development themes, using the order of aligned trials within each ID and day. The predecessor analysis excludes the first trial. Normalizing rank by session length assumes the length is known. Report time-order protocols separately for cohorts 1–2 and 3–5. A null index-only classifier does not exclude a local block effect when block order is randomized.
- **Figure 1A.** Recalculate all 15 bins on each historical split and report the number of finite individual effects for each modality and bin. The historical 235 is a label-eligibility count. The classification development set has 228 IDs before endpoint-specific eligibility.

## Heart-rate forecasting

The target and 57 body features are those extracted from CURATED peripheral channels in Study 09. The target is HR during [5,10) seconds minus HR during [−3.5,0). Its pre-clip reference is also available to the baseline model. The comparison uses the same eligible trials and folds for all models.

1. Load the 62 EEG channels from CURATED only. Crop before QC and filtering, apply a forward 0.5–45 Hz bandpass, downsample to 200 Hz and apply a common-average reference over valid electrodes. Use the 8.2 seconds before the cutoff at 5 seconds; compute the pre-onset control on its own prefix cut at zero. Perturb samples at and after each boundary and verify that both the inputs and frozen encoder outputs are identical. These tests concern data availability by the prediction instant.
2. Reserve a deterministic, cohort-stratified subset of development IDs solely for estimating an ECG-to-EEG transfer function. These IDs never enter predictive CV. Fit the 0–120 ms ECG lag regression on up to 16 epochs per calibration recording. Freeze the coefficients and report held-out EEG–ECG coupling before and after subtraction. A population transfer function cannot remove every individual cardiac artefact; attenuation can also remove genuine cardiac-locked neural activity.
3. Compare the original 57-feature body model, the late RR sequence alone, and a stronger baseline combining the original features, up to 16 recent RR intervals, time since the last beat, and half-second summaries of the raw ECG, EDA and respiratory waveform. Compare manual EEG features, archived release-derived REVE, raw uncorrected REVE, and raw ECG-corrected REVE. Report a nonlinear body baseline and a nonlinear corrected-EEG comparison. REVE is frozen.
4. The primary comparison is strong body plus corrected raw REVE versus the same strong body model. Report paired within-ID correlation gain and RMSE reduction in bpm with 95% ID-bootstrap intervals. Secondary comparisons include the difference between corrected and uncorrected raw EEG, same-video substitution with a strictly different donor ID, within-ID trial shuffling, pre-onset EEG, and 46 interior channels. Evaluate substitution and real EEG on the same donor-eligible rows. Compare the MSE benefit between distress and non-distress trials within IDs with at least three trials of each class. Secondary controls are exploratory.

## Reproduction

The CPU workflow downloads private trial tables into ephemeral HABS-authenticated GitHub runners. The GPU workflow stages only the development grid and pinned extraction helpers from commit `501d24b` into a private HABS job. The raw scoring workflow retrieves the private feature table and returns aggregate metrics. Retain workflow attempt numbers, input/output checksums, the current commit, the two frozen model revisions and the analysis populations when reporting results.
